# Patterns

## Working Style
- **Self-host before paying** — the same MIT software ran locally with no bill, so a hosted plan is the last resort (2026-11-01)
- **Verify before claim** — paste the build or test output; no error is not the same as done (2026-08-20)
- **Consolidation over accumulation** — merge before multiplying skills; check if the capability exists first (2026-04-05)
- **Knowledge must pay rent** — every distilled page ends with a Brain Impact verdict and a stated context cost (2026-11-02)
- **Scope defaults to the current thread** — an instruction after a long thread on X is about X unless said otherwise (2026-08-21)
